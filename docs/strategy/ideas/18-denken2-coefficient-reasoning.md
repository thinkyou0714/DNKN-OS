# 18 — 三種→二種の断層と係数リーズニング（最後の一撃）

> 電験三種合格者が二種で最初に折れるのは、知識量ではなく**理解の質の断層**である。
> 本書は「三種合格者が二種でつまずく点」の深堀り調査と、その中で唯一アプリが未対応だった
> 「係数の壁」への一撃 — **係数リーズニング・ドリル** — の設計・実装記録。

## 1. 深堀り調査: 三種合格者はどこで折れるか

三種は5択マーク・公式当てはめで合格圏に届く。二種は一次こそマークだが、
二次（電力・管理／機械・制御）は**記述式で導出過程そのものが採点対象**になる。
このモード変化が4つの壁として現れる。

| # | 壁 | 実態 | 本リポジトリの対応状況 |
|---|---|---|---|
| 1 | **記述の壁** | 途中式・仮定・単位を書けないと部分点が取れない。二種は二次で最も落ちる | ✅ 部分点ルーブリック（09参照）・導出並べ替えドリル・descriptive テンプレ |
| 2 | **数学の壁** | ラプラス変換・微分方程式・複素平面の運用が前提になる | ✅ 自動制御テンプレ群・原理カード「自動制御理論」（拡充は継続） |
| 3 | **係数の壁** | √3・1/2・√2・2 を「おまじない」として暗記していると、単位法で√3が消え、対称座標法で 1/3 と 3 が現れる二種の流儀に対応できない | ❌ **未対応だった → 本書で実装** |
| 4 | **体系の壁** | 前提概念の欠けが応用分野で一気に露呈する | ✅ 前提DAG・体系ロードマップ・根っこ診断・納得チェック |

### 係数の壁の解剖

三種合格者が「解けるのに説明できない」係数の典型:

- **√3**: Y の線間電圧・Δ の線電流に付く（120°差ベクトルの差の幾何）。Δ の線間電圧・Y の
  線電流には付かない。単位法の中では基準に吸収されて**消える**。
- **1/2**: 蓄積エネルギー（CV²/2・LI²/2・Jω²/2）は積分由来。実効値表記の電力には
  1/2 は不要（√2 換算に吸収済み）— 振幅表記なら必要。
- **√2**: 正弦波**専用**の波高値↔実効値換算。直流・方形波には使わない。
  4.44（= 2π/√2）の正体もここ。
- **2**: 単相2線の「往復」。三相の √3（線間換算）と混同しやすい。
- **1/3・3**: 対称座標法。零相は「平均」だから 1/3、地絡電流は「和」だから 3I0。
- **消える係数**: 単位法では √3 も巻数比² も消える。どの世界で計算しているかの自覚が要る。

三種の学習法（公式暗記→数値当てはめ）はこの使い分けを**問われないまま**通過させる。
二種二次で初見の設定に出会った瞬間、「√3 を掛けるんだっけ、割るんだっけ」で崩れる。

## 2. 最後の一撃: 係数リーズニング・ドリル

**「同じ量でも、状況が変われば係数が変わる」最小対比ペアを判断問題として反復する。**

既存機能との違い:

- 原理カード / 納得チェック … 説明を**読む・思い出す**（自己申告採点）
- 導出並べ替えドリル … 手順の**順序**を組む
- 電卓速算ドリル … √3×n の**計算**を速くする
- **係数判断ドリル（新規）** … この状況で係数は**要るか要らないか**を客観採点で判断する

判断（discrimination）の訓練だけが「いつ必要でいつ不要か」を直接鍛える。これが最後のピース。

### 設計（実装済み）

- `lib/curriculum/coefficients.ts` — 純ロジック＋コード所有コンテンツ（LLM 生成なし）
  - 係数**ファミリ** 6件（√3・1/2・√2・2・対称座標・単位法）: 由来 origin / 要る場面 /
    要らない場面 / 二種でどう化けるか（denken2Note）
  - **判断ドリル** 26問: 状況文 + 係数の選択肢 + 正解 + なぜ(why) + **最小対比(contrast)**。
    ID は `family#index` で安定（記憶状態のキー。途中挿入・並べ替え禁止、追加は末尾のみ）
  - 出題は why-check と同じ定石（期限到来の再固定を最優先 → 未着手を定義順）
  - 正誤を FSRS 評価へ2値写像（正解=good / 不正解=again。客観採点なので自己申告4段階は不使用）
  - ファミリ進捗集計と「いちばん混ざっている係数」（lapses 最多）の推定
- `web/src/coeff-store.ts` — `denken:coeffCards` に FSRS 状態を永続化（演習・納得チェックとは
  別キー。正答率・XP・弱点診断を汚さない）。バックアップ対象に追加
- UI 統合（3導線）
  - 復習タブ: 「係数の使い分けドリル」セクション（期限到来分の間隔反復）
  - 学習タブ: スキルドリルランチャーに「⚖️ 係数判断ドリル」
  - 進捗タブ: 「⚡ 三種→二種ブリッジ」— ファミリ別進捗と苦手係数の確かめ直し導線
- テスト: `tests/curriculum/coefficients.test.ts`（ゴールデンID表・出題順・採点・進捗）、
  `tests/web/coeff-store.test.ts`（FSRS 更新・分離・破損耐性）

### 学習フローの中での位置づけ

```
原理カード（なぜ成り立つか）
  → 納得チェック（自分の言葉で言えるか・FSRS）
  → 係数判断ドリル（使い分けを判断できるか・FSRS）★新規
  → 演習（解けるか・FSRS）
  → 二種ひねりテンプレ（denken2_primary / denken2_secondary）
```

「読める→言える→判断できる→解ける」の階段が揃い、
係数を由来から運用できる状態＝二種の記述で式を自分で組み立てられる状態へ橋を架ける。
