# 19 — 部分点ルーブリックの深化と誤概念のフィードバックループ

> 18（係数リーズニング）で「係数を由来から使い分ける」訓練を入れた。本書はその続きで、
> **(A) 二次記述の採点をより本番に近づける**、**(B) 誤答の中身を読んで原因を名指しし、
> 訓練へ送り返す**の2つを実装した記録。両者は独立した機能ではなく、
> 「間違える → 原因が分かる → 直す場所へ飛ぶ」という1本のループを閉じるための対です。

## 1. 部分点ルーブリックの深化（配点重み・必須キーワード）

### 直した歪み

旧実装は模範解答のステップ数を**等重み**で数えていた。実データ（記述 2,766問）を調べると
2つの構造的な歪みがあった。

| # | 歪み | 実害 |
|---|---|---|
| 1 | 「ポイント:」「（補足: …）」の行まで1点として数えていた | 全ステップ 12,946 行のうち **3,186 行（24.6%）が採点対象外の行**。本番なら満点の答案でも部分点が 3/4・4/5 にしかならず、FSRS 評価まで不当に下がっていた |
| 2 | 方針・公式・代入・最終値がすべて同じ重み | 実際の採点は「最終値と単位」が最も重い。配点感覚が本番とずれる |

これは機能不足というより**採点の正しさの問題**だった。修正後は全 2,766 問で
「採点対象を全部チェック＝満点(easy)」が成立する（テストで恒久的に保証）。

### 設計

`lib/curriculum/rubric.ts` が模範解答の文面だけから決定論的にルーブリックを組む。
**問題データのスキーマは変更していない**ため、既存 9,354 問にそのまま効く
（リポジトリの「生成物はコードから決定論的に導く」方針に一致）。

| 役割 | 判定 | 配点 |
|---|---|---|
| 着眼 approach | 「着眼点/方針…」で始まる | 1 |
| 公式 formula | 等号を含み数値リテラルなし | 2 |
| 代入 substitution | 等号を含み数値リテラルあり | 2 |
| 計算 calculation | 等号なし | 2 |
| 結論 conclusion | 採点対象の**最後**の等式（最終値と単位） | 3 |
| 補足 note | 括弧始まり・「ポイント/補足/注意…」 | **0（採点対象外）** |

補足事項:

- 添字の数字（`r2/s1`）は数値リテラルとみなさない。`比例推移: r2/s1=(r2+R)/s2` は
  「代入」ではなく「公式」に分類される。
- 公式と代入は**同じ重み 2**。文面依存で判別が揺れても点数は変わらない（安全側の設計）。
- 全行が補足の異常データでも採点が成立するようフォールバックする。

### 必須キーワード判定

各項目から「数値＋単位（`39.6kW`）」「単位なしの数値リテラル」「等号左辺の量記号（`Vo`）」を
抽出する。学習者が答案を書き写すと、キーワード一致率 60% 以上の項目をチェック候補として提案する。

- あくまで**提案**。文章表現の正しさは機械には測れないので、最終判断は学習者が行う。
- 採点対象外（重み0）の項目は提案しない（点にならない操作を促さない）。
- **単位落としの指摘**を別途行う。二次の典型的な減点であり、模試タブの記述でも
  （○×判定は本番再現のまま変えずに）答案に無い単位を警告するようにした。

## 2. 誤概念のフィードバックループ

### 着想

電験の誤答の多くは計算力不足ではなく**係数の取り違え**であり、そのとき
「選んだ値 ÷ 正解値」の比は特徴的な定数になる。比を読めば原因を名指しできる。

| 比 | 誤概念 | 送り先の係数ファミリ |
|---|---|---|
| √3 / 1/√3 | √3 を余分に掛けた / 掛け忘れた | `sqrt3` |
| 3 / 1/3 | √3 と 3 の取り違え（相数・対称座標の 3I0） | `sqrt3` |
| √2 / 1/√2 | 実効値↔最大値の換算ミス | `sqrt2` |
| 2 / 1/2 | 往復2線分・エネルギーの 1/2 | `two` / `half` |
| 2π / π とその逆数 | ω=2πf と f の取り違え | `omega` |
| 1.11 / 0.90 | 波形率の掛け違い | `waveform` |
| 100 / 0.01 | ％と実数の取り違え | `perunit` |
| 1000 / 0.001 | 単位接頭辞 k | （単位・ドリル対象外） |
| −1 | 符号の取り違え | （ドリル対象外） |

### 設計上の判断

- **許容誤差は 1% と狭く取る。** 採点自体は 0.5% 許容なので、√3 を 1.7 で概算した程度の
  「丸めが粗いだけの不正解」を係数ミスと誤診断すると学習者を混乱させる。
  1.7/1.732 = 0.981 はパターンに一致しない（テストで固定）。
- **分類は保存時ではなく読み出し時に行う。** ログには誤答値（`chosen`、24文字に切り詰め）だけを
  残し、パターン表は後から増やせるようにした。過去のログにも新しい分類が遡って効く
  （XP を解答ログから完全導出しているのと同じ方針）。
- **当てはまらない誤答は無理に分類しない。** 「分類できなかった N 件」として正直に表示する。

### ループが閉じた

```
演習で誤答（chosen を記録）
  → 進捗タブ「🧩 誤答パターン」で原因を名指し（推定と明示）
  → 「⚖️『√3』で確かめ直す」でその係数ファミリのドリルへ直行
  → 係数判断ドリルを FSRS で反復
  → 演習に戻る
```

18 で作った係数ドリルは「良い訓練だが、いつ誰がやるべきか」の入口が
自己申告しかなかった。誤答分析がその入口を**データで**作った。

## 3. 係数ファミリの拡張

誤概念表が π・2π・1.11 を指せるようにするため、係数ファミリを 6 → 9 に増やした
（ドリル 26 → 39 問）。

- `omega` — ω=2πf（角速度と周波数）。リアクタンス・共振・s=jω 置換で要る／Ns=120f/p では不要。
- `waveform` — 波形率 1.11・波高率 √2・全波整流の平均値 2/π。正弦波専用の係数であることが核心。
- `base` — 三相/単相の基準の違い。Ib=Sb/(√3Vb)、Zb=Vb²/Sb（√3 が約分で消える）、単相機器の %Z 換算。
